# WASM Playground (source directory)

Browser playground served as the GitHub Pages site root. See [../wasm-playground.md](../wasm-playground.md)
for build, architecture, deployment and troubleshooting.

`wasm.wasm`, `wasm_exec.js` and `static-tiles/` are generated by `just build-wasm` (and by CI); they
are not committed. Run `just build-wasm-local` and open <http://localhost:8000/wasm-playground/>.
